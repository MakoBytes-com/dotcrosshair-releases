# DOT Crosshair downloads

Signed Windows installers for [DOT Crosshair](https://dotcrosshair.com), a free custom crosshair overlay for PC games by Mako Logics LLC.

Get the latest version from **https://dotcrosshair.com/download**. Every package here is signed by Mako Logics LLC; Windows checks that signature before installing.

This repository holds release files only. Questions: support@dotcrosshair.com
